Install on iPhone / iPad

iPhone / iPad · Safari

Apple doesn't allow apps to install themselves — you'll do it in 3 quick taps:

  1. Tap the Share button ⬆ at the bottom of Safari (middle of the bar)
  2. Scroll and tap "Add to Home Screen"
  3. Tap Add in the top-right
Not seeing the Share button?

Make sure you opened this page in Safari (not Chrome or another browser). Apple only supports adding to home screen from Safari.

Please open in Safari

iPhone · Chrome

Apple only allows installing web apps through Safari. Please:

  1. Copy this link: sankirtan.app/install
  2. Open Safari (the blue compass icon)
  3. Paste and go — then follow the 3 steps to install

Install on Desktop

Desktop
Preparing install…
Or install manually
  1. Look for the install icon ⊕ at the right end of the address bar
  2. Click it and confirm
  3. The app opens in its own window and appears in your apps list

Works in Chrome, Edge, and other Chromium browsers. Safari on Mac doesn't currently support PWA install from the address bar — use "File → Add to Dock" instead.

Add Sankirtan to your device

Open sankirtan.app in your device's default browser (Chrome on Android, Safari on iPhone), then use the browser menu to "Add to Home Screen" or "Install App".

Sankirtan is a Progressive Web App (PWA) — no download required. It installs directly from the browser and works offline once loaded.
